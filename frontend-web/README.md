# Frontend Web MVP

## Scope
- Role-based web console for Job Seeker, Company, and Admin
- API integration skeleton aligned with `backend-nestjs`

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## API Base URL
- Set `VITE_API_BASE_URL` in `.env`
- Default: `http://localhost:3000/api`
